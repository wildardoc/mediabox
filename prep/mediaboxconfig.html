Mediabox Container Management

Portainer:
To help you manage your Mediabox Docker containers Portainer is available.
Portainer is a Docker Management UI to help you work with the containers etc.
A password will need to be set for the admin account upon initial login.

Manual Configuration steps:

Radarr:
  • Click on the Settings icon
  • Click on the Download Client Tab
  • Click on the + sign to add a download client
  • Under the "Torrent" section Select Deluge
  • Enter these settings:
    * Name: Deluge
    * Enable: Yes
    * Host: locip
    * Port: 8112
    * Password: deluge (unless you have changed it)
    * Category: blank
    * Use SSL: No
  • Optional: Click on the media management tab and configure the renamer

Sonarr & Lidarr
  • Same instructions as Radarr

Maintainerr (Media Cleanup):
Maintainerr automatically removes unwatched media to free up space while protecting content you want to keep.

Initial Setup:
  • Open Maintainerr: http://locip:6246
  • Connect to Plex (Settings → Plex → Add your server)
  • Optionally connect Overseerr and Tautulli for enhanced data
Creating Exclusion Collections (Recommended First Step):
  1. In Plex, go to your Movies library
  2. Click Collections → Create Collection → Name it "Never Delete"
  3. Add movies you want to keep forever to this collection
  4. Repeat for TV Shows library (entire series can be added - new episodes auto-included)
Example Rules:
  • Movies: Delete unwatched movies older than 90 days, EXCEPT those in "Never Delete" collection
  • TV Shows: Keep only the latest season, delete older seasons, EXCEPT shows in "Never Delete" collection
Creating a Rule with Exclusions:
  1. Go to Rules → Create Rule
  2. Add conditions for what to delete (e.g., "Days since added" > 90, "Times played" = 0)
  3. Add exclusion: "Collection" → "is not" → "Never Delete"
  4. Set action to "Delete from Plex" or "Delete from Disk"
  5. Enable the rule and set a schedule
Tips:
  • Start with rules in "dry run" mode to preview what would be deleted
  • Use Plex labels (e.g., "keep") as an alternative to collections
  • Adding an entire TV series to a collection protects all current and future episodes
FlareSolverr (Cloudflare Bypass):
FlareSolverr is automatically configured in Prowlarr during setup.
If you need to configure it manually:
  • Open Prowlarr: http://locip:9696
  • Go to Settings → Indexers
  • Click the + button under "Indexer Proxies"
  • Select "FlareSolverr"
  • Enter Host: http://locip:8191
  • Request Timeout: 60 seconds
  • Click Save
Once configured, assign the flaresolverr tag to any indexers that require Cloudflare bypass.
To verify FlareSolverr is running: http://locip:8191
